Different embedding models represent text in distinct semantic latent spaces. Instructions
Pull both models in your local Ollama: ollama pull nomic-embed-text and ollama pull mxbai-embed-large.

Embed all 50 sentences using both models and normalize each embedding to unit length (L2 norm).
Build two separate faiss.IndexFlatIP indexes: Index A for nomic-embed-text and Index B for mxbai-embed-large.

Retrieve the top-3 nearest document indices from Model A: [idx_a1, idx_a2, idx_a3].
Retrieve the top-3 nearest document indices from Model B: [idx_b1, idx_b2, idx_b3].
Calculate the Spearman rank correlation (ρ) between Model A's and Model B's similarity rankings across all 50 corpus documents.
Submit a 10×7 JSON matrix: [[idx_a1, idx_a2, idx_a3, idx_b1, idx_b2, idx_b3, rho], ...].
